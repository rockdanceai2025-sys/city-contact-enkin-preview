# コンテンツページ｜コンタクトレンズを購入するなら、眼科併設のコンタクトショップを選びましょう！

シティコンタクト（株式会社エーアイピー）様のコーポレートサイトへ組み込むことを想定した、
**1ページ完結のコンテンツページ**です。

## 制作にあたって参照したもの（これ以外は参照していません）

1. 指示書 `instructions_contactshopwitheyeclinic_1.md`
2. ご支給いただいたコーポレートサイトのスクリーンショット（トンマナ確認用）
3. 内部リンクのURL確認（Web検索で city-contact.com の実在ページを確認）

※ この作業環境からは `www.city-contact.com` へ直接アクセスできません（ネットワークポリシーによる遮断）。
そのため配色・ヘッダー・ボタン形状は**ご支給スクリーンショットからの読み取り**です。正式なカラーコードや
共通パーツのHTMLをいただければ、より正確に合わせられます。

## ファイル構成

```
eyeclinic/

│   └── js/main.js        … フェードインのみ（ライブラリ不使用）
```

## 1. 組み込み時に差し替えが必要な箇所

| 箇所 | 現在の状態 | 対応 |
| --- | --- | --- |
| ヘッダー／アイコンナビ | スクショを目視で再現した簡易版（HTMLにコメント明記） | 本物の共通ヘッダーに差し替え |
| フッター | スクショに写っていないため、指示書の内部リンク要件に基づく簡易版 | 本物の共通フッターに差し替え |
| `<meta name="robots" content="noindex, nofollow">` | 確認用に付けています | **本番公開前に必ず削除** |
| title / description / keywords | 仮設定 | SEO方針にあわせて調整 |
| canonical / og:url | `https://www.city-contact.com/column/eyeclinic/` を仮置き | 掲載URL確定後に差し替え |
| og:image | パスのみ仮置き（画像は未作成） | 既存サイト素材またはご支給素材を指定 |
| パンくず | 「ホーム ＞ 初めての方 ＞ 本ページ」で仮置き | 実際の階層にあわせて調整 |

## 3. 見出し構成（指示書 5. に準拠）

1. H1：コンタクトレンズを購入するなら、眼科併設のコンタクトショップを選びましょう！
2. 導入文（結論先出し）
3. H2：なぜ「眼科併設」が安心なのか（流れ図＋4つの安心＋処方を受けずに購入する場合との違い）
4. H2：コンタクトショップ選びで失敗しないポイント（眼科併設／取扱ブランド／専門知識／アフターサポート）
5. H2：シティコンタクトが選ばれる理由（九州・山口の店舗展開／メニコングループ／豊富な取扱商品）
6. H2：お得に続けられる「メルスプラン」のご紹介
7. H2：ご来店の流れ（4ステップ）
8. CTA（まとめ）

CTAは **FV／眼科併設章／ポイント章／選ばれる理由章／メルスプラン章／ご来店の流れ章／まとめ／右下追従バー** の8か所。
ボタン文言は指示書どおり「店舗一覧を見る」「メルスプランを詳しく見る」「初めての方へ」を使用しています。

**章立ては指示書の「たたき台」に沿ったものです。** クライアント様から確定構成が出た場合はそちらを優先し、差し替えます。

## 4. 原稿・表現について（薬機法・景品表示法）

- 効果効能の断定表現は使用していません。「相談できる」「確認できる」という**体制・利便性の事実**にとどめています。
- 他社・他の購入方法を貶める表現は避け、「ご自身で度数を指定して購入する場合」として**事実ベースの違い**のみ記載。
- 症状の医学的説明には踏み込まず、「異常を感じたらすぐ相談できる」という安心感の訴求にとどめています（指示書 5-3 に準拠）。
- 「無料」表現は使用していません。**「眼科での検査・診察には、別途 費用（保険診療の場合は自己負担分）が必要です」**を
  FV・ご来店の流れ・まとめCTAの3か所に明記しています。
- 高度管理医療機器としての注意文（添付文書・定期検査・異常時は使用中止のうえ眼科医へ相談）をページ下部に記載。
- **数値・実績・店舗数・電話番号などの具体値は一切記載していません。** 指示書とスクショに無い情報は書いていません。
  掲載が必要であればご指示ください。

## 5. 配色（`assets/css/style.css` の `:root`）

スクリーンショットからの読み取り値です。正式値をいただければ1か所の差し替えで全体に反映されます。

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--c-pink` | `#ef7ea6` | メインピンク（塗りCTA・アイコン） |
| `--c-pink-dark` | `#e05a8a` | 見出し・ホバー |
| `--c-pink-deep` | `#d6006c` | ロゴ・強調 |
| `--c-pink-light` | `#fce9f0` | 淡いピンク背景 |
| `--c-pink-pale` | `#fff6f9` | さらに淡い背景 |
| `--c-orange` | `#f2903c` | ロゴドットの差し色 |
| `--c-text` / `--c-text-sub` | `#4a4348` / `#857b80` | 本文／補足 |

ボタンはスクショに合わせ、**pill型（完全な角丸）**で「白地＋ピンク枠」と「ピンク塗り」の2種類。
右下の追従CTA（来店・相談会予約／店舗一覧）もスクショに合わせて再現しています。

## 6. 画像について

- 流れ図はHTML/CSSで作図、アイコンは細線のインラインSVGです。画像ファイルは1つも使っていません。

## 7. 表示確認の結果

Chromium（Playwright）で実測。

| 画面幅 | ページの横スクロール | JSエラー |
| --- | --- | --- |
| PC 1280px | なし | なし |
| タブレット 900px | なし | なし |
| スマホ 390px | なし | なし |

- スマホではアイコンナビのみ横スクロール（意図的）。ページ本体は横に溢れません。
- 640px以下で、右下CTAが画面下部の全幅バーに切り替わります。
- `prefers-reduced-motion` 設定時はアニメーションを停止します。
