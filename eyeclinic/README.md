# コンテンツページ｜コンタクトレンズを購入するなら、眼科併設のコンタクトショップを選びましょう！

シティコンタクト（株式会社エーアイピー）様のコーポレートサイトへ将来的に組み込むことを想定した、
**1ページ完結のコンテンツページ**です。指示書 `instructions_contactshopwitheyeclinic_1.md` に沿って制作しました。

- 成果物：`index.html` ＋ `assets/`（CSS・JS・画像）。ビルドツール・CMS環境に依存しません
- そのままブラウザで開いて確認できます（`index.html` をダブルクリック）
- 実際のサイトへの組み込み（CMS反映）は、クライアント様または制作会社様にて行っていただく前提です

## 1. 組み込み時に差し替えが必要な箇所

| 箇所 | 現在の状態 | 対応 |
| --- | --- | --- |
| ヘッダー | 既存サイトの見た目に寄せた簡易版（`<!-- ここは実際のサイト組み込み時に共通ヘッダーに差し替え -->`） | 本物の共通ヘッダーに差し替え |
| フッター | 同上（リンク構成の簡易版） | 本物の共通フッターに差し替え |
| `<meta name="robots" content="noindex, nofollow">` | 確認用に**noindexを入れています** | **本番公開前に必ず削除**（残すと検索結果に出ません） |
| `title` / `description` / `keywords` | 仮設定 | SEO方針にあわせて調整 |
| `canonical` / `og:url` / `og:image` | `https://www.city-contact.com/column/eyeclinic/` を仮置き | **掲載URL確定後に差し替え** |
| パンくず | 「ホーム ＞ 初めての方へ ＞ 本ページ」で仮置き | 実際の階層にあわせて調整 |
| `assets/img/ogp.svg` | SVGで作成 | SNS表示の互換性のため PNG（1200×630）へ書き出して差し替え推奨 |

## 3. 原稿・表現について（薬機法・景品表示法）

- **効果効能の断定表現は使用していません。** 「目が良くなる」「トラブルを防げる」等は避け、
  「相談できる」「確認できる」という**体制・利便性の事実**にとどめています。
- **他社・他購入方法の誹謗にあたる表現は避けています。** ネット通販等については
  「ご自身で度数を指定して購入する場合」として、**事実ベースの違い**のみを記載しました。
- **「無料」表現の扱い**：眼科の検査・診察には診察料がかかるため、無料と受け取られる表現は使っていません。
  「**レンズ選びのご相談は無料です**」（＝店舗でのレンズ相談のみ）に統一し、
  FV・ご来店の流れ・CVの3か所に「**眼科での検査・診察には、別途 診察料（保険診療の場合は自己負担分）が必要です**」を明記しています。
- 高度管理医療機器としての注意文（添付文書・定期検査・異常時は使用中止のうえ眼科医へ相談）をCV下部に記載しています。
- 「全店 眼科併設」の表現は、既存制作物でのご指示（「眼科提携」ではなく「全店 眼科併設」に統一）を踏襲しています。
  **表記が変更になる場合はご指示ください。**

## 8. 確認用（パスワード付き）ページの作り方

クライアント様への共有用に、パスワードで保護した確認ページを発行できます。

```bash
python3 tools/build-preview.py                 # 1ファイル版 preview.html を生成
node tools/build-encrypted.js <パスワード>      # preview.html → site.bin（AES-256-GCM）
```

生成した `site.bin` と、パスワード入力画面（`tools/gate.html` を案件用に書き換えたもの）を
公開用リポジトリに置くと、GitHub Pages でパスワード付きの確認URLとして公開できます。
※ 本リポジトリのルートには、**既存の「遠近両用ページ」の確認用ページ**が公開中です。上書きしないようご注意ください。
